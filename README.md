# Сервис Публикации Вакансий

Краткое описание: данный проект - это набор микросервисов, предоставляющий REST API для публикации вакансий с акцентом на чистую архитектуру, тестируемость и облачную развёртку.

**Технологии:**
- **Язык:** Java
- **Frameworks:** Spring Boot, Spring Cloud (Eureka, Config), Spring Data JPA, Spring Security (JWT)
- **Messaging:** Apache Kafka
- **Миграции:** Flyway
- **Тестирование:** Testcontainers, JUnit 5
- **Сборка/Деплой:** Gradle, Docker, Docker Compose
- **Документация:** OpenAPI/Swagger


**Файлы/модули проекта:**

- `vacancyService` — основной сервис для управления вакансиями: CRUD, статусные переходы и поиск.
- `userService` — управление пользователями и аутентификацией (JWT), хранение профилей и авторизационных данных.
- `organizationService` — управление организациями и их метаданными.
- `notificationService` — генерация и рассылка уведомлений через Kafka и WebSocket для realtime-оповещений.
- `fileService` — загрузка и хранение файлов (резюме, изображения), интеграция с локальным/облачным хранилищем.
- `gatewayService` — API Gateway: маршрутизация, агрегация запросов и централизованная точка входа.
- `eurekaServer` — сервис реестра для динамического discovery микросервисов.
- `configServer` — централизованное хранение конфигураций (Spring Cloud Config).
